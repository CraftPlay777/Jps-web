Jps

基于OpenStreetMap的地图应用，无广告、无账号、无API密钥

下载 APK
需要 Android 6.0 或更高版本 · 免费 · 开源（MIT）

Jps 是一款简单的地图应用，没有广告、不需要账号，也没有追踪器。它使用 OpenStreetMap 地图和开放服务，因此不需要 Google 服务或 API 密钥。

功能

  • 地点搜索，带搜索历史和收藏夹
  • 我的位置（GPS）、缩放、比例尺和指南针
  • 双指旋转地图
  • 可选择五种地图样式
  • 精确显示所搜索区域的轮廓
  • 国家和省/州边界，可用颜色或国旗标注
  • 3D 地球仪，带地形起伏模式
  • 路线导航：汽车、摩托车、卡车、自行车或步行，显示预计时间和路线步骤
  • 地点信息卡中显示维基百科的照片和介绍
  • 分享和复制坐标
  • 四种语言：西班牙语、英语、中文和法语
  • 浅色、深色或跟随系统主题
